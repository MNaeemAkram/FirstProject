Simple Calculator (Python + Tkinter)
A basic GUI calculator built with Python's built-in tkinter library. This is a beginner project made to practice GUI programming, functions, and event handling in Python.

Features
Basic operations: addition (+), subtraction (-), multiplication (*), division (/)
Percentage (%) button
Decimal point support
Backspace (⌫) button to delete last entered character
Clear (C) button
Handles division by zero and invalid input errors

How to Run
Make sure Python is installed (Python 3.x recommended)
tkinter usually comes pre-installed with Python
Run the file:
python calculator.py
Technologies Used
Python 3
Tkinter (built-in GUI library)
